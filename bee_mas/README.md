# Bee-MAS 智能多Agent系统

## 🐝 系统概述

Bee-MAS是一个基于蜂群智能的多Agent系统，专门用于工程设计和任务调度。系统模拟了蜜蜂社会的分工协作机制，通过智能工蜂的协作来完成复杂的工程任务。

## 🏗️ 系统架构

### 核心组件

1. **调度蜂 (SchedulerBee)** - 负责任务分解、分配和协调
2. **工况分析蜂** - 专业的需求分析和参数计算
3. **三维建模蜂** - 3D建模和OpenSCAD脚本生成
4. **装配蜂** - 装配设计和空间定位

### 工作流程

1. **任务分解** - 将用户需求分解为子任务
2. **任务发布** - 发布到任务公告板
3. **智能竞标** - 工蜂自动分析并提交提案
4. **任务分配** - 基于评分智能分配任务
5. **任务执行** - 工蜂执行分配到的任务
6. **结果收集** - 收集和整合任务结果

## 🚀 快速开始

```bash
pip install -r requirements.txt
```

```bash

```

## 🔧 功能特性

### 工况分析蜂 - 参数生成

工况分析蜂是系统的核心组件，负责：

- **需求分析** - 将自然语言需求转化为结构化参数
- **参数计算** - 生成精确的工程参数
- **约束识别** - 识别设计约束和限制条件
- **设计建议** - 提供专业的设计建议

#### 示例输出

```json
{
  "parameters": {
    "模数": 2.0,
    "齿数": 20,
    "压力角": 20,
    "齿宽": 10,
    "孔径": 15
  },
  "units": {
    "长度": "mm",
    "角度": "度"
  },
  "constraints": [
    "使用标准规格",
    "考虑制造可行性"
  ],
  "recommendations": [
    "建议进行详细设计验证"
  ]
}
```

### 智能任务调度

- **依赖管理** - 自动管理任务间的依赖关系
- **负载均衡** - 智能分配任务给最合适的工蜂
- **进度跟踪** - 实时监控任务执行状态
- **错误处理** - 自动处理任务执行异常
